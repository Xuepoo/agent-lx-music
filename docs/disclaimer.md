## 1. Data Sources

1.1 The online data from each official music platform is pulled directly from their public servers (equivalent to requests sent by unauthenticated guest users via the official platforms' apps). The data is presented after basic filtering and merging. Therefore, this project assumes no responsibility for the legality, validity, or accuracy of such data.

1.2 This project itself has no native capability to bypass or obtain arbitrary audio streams. The online audio sources are fetched from links returned by the external APIs chosen by the User under the "Custom Source" setting. For instance, when playing a track, this project merely transmits metadata (e.g., song title, artist) to the configured custom source. If the custom source returns a link, this project will attempt to play it under the assumption that it is the correct audio file. This project is unable to verify the correctness or authenticity of the returned stream; hence, issues such as incorrect audio files or playback failures may occur.

1.3 Non-official platform data (such as local playlists under "My Playlists") is sourced from the User's local system or external synchronization servers configured by the User. This project assumes no responsibility for the legality or accuracy of such user-supplied data.
